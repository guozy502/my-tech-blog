# 回溯、贪心与图算法——组合穷举、最优决策到网络建模

> 回溯是穷举的艺术，贪心是局部最优的赌博，图算法是对真实世界的网络建模。这三种思维模式覆盖了面试中 "非 DP 非数据结构" 的所有核心算法题。本文不讲死记硬背，讲每种算法的**决策框架**——回溯的选/不选决策树、贪心的证明路径、图算法的遍历骨架。

---

## 一、回溯

### 1.1 核心框架——一棵决策树的 DFS

回溯的本质：**在决策树中做 DFS，每条路径就是一种可能的结果**。关键在于两件事：什么条件下可以选（剪枝），选完后怎么撤销。

```python
# 回溯骨架
def backtrack(路径, 选择列表):
    if 满足终止条件:
        result.append(路径[:])   # 深拷贝！
        return
    
    for 选择 in 选择列表:
        if 不合法: continue      # 剪枝
        做选择                    # 路径.add(选择)
        backtrack(路径, 新选择列表)
        撤销选择                  # 路径.pop()
```

### 1.2 三种基础模板——排列、组合、子集

**子集**：每个元素选或不选。不需要 start 也能做，但用 start 避免重复分支。

```python
def subsets(nums):
    res = []
    def backtrack(start, path):
        res.append(path[:])           # 每个节点都收集（不是只在叶子收集）
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)    # i+1：不重复选
            path.pop()
    backtrack(0, [])
    return res
```

**组合**：从 N 个元素中选 K 个。跟子集几乎相同，只是加了长度限制。

```python
def combine(n, k):
    res = []
    def backtrack(start, path):
        if len(path) == k:
            res.append(path[:])
            return
        # 剪枝：剩余元素不够凑齐 k 个 → 不用再递归
        # 还需要 k - len(path) 个，到 n - (k-len) + 1 为止必须停止
        for i in range(start, n - (k - len(path)) + 2):
            path.append(i)
            backtrack(i + 1, path)
            path.pop()
    backtrack(1, [])
    return res
```

**排列**：每次从头遍历所有剩余元素（选过的跳过）。

```python
def permute(nums):
    res = []
    used = [False] * len(nums)
    
    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]: continue              # 已选过的跳过
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False
    
    backtrack([])
    return res
```

**三种模板的唯一区别**：

| | 子集 | 组合 | 排列 |
|---|------|------|------|
| start 参数 | i+1 | i+1 | 无（从头遍历） |
| 收集时机 | 每个节点 | 叶子节点（长度==K） | 叶子节点（长度==N） |
| 去重方式 | start 限制 | start 限制 | used 数组 |

### 1.3 去重模板——排序 + 同级跳过

```python
# 含重复元素的子集去重
def subsets_with_dup(nums):
    nums.sort()   # 先排序！让相同元素相邻
    res = []
    def backtrack(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i-1]:
                continue  # 同一层跳过重复元素
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    backtrack(0, [])
    return res
```

核心：`if i > start and nums[i] == nums[i-1]: continue`。`i > start`（不是 `i > 0`）保证只在**同一层递归**中去重——不同层允许相同元素出现（如 `[2,2]` 是合法子集）。

### 1.4 实际场景

- **SQL Join 顺序优化**：N 个表的 JOIN，回溯枚举所有可能的 JOIN 顺序 → 选代价最小的
- **正则表达式匹配**：`a*b?c` 匹配文本——回溯尝试 * 匹配 0 次、1 次、2 次...
- **N 皇后/数独**：经典约束满足问题——回溯 + 剪枝
- **包依赖解析**：Maven/Gradle 的依赖版本冲突解决——回溯尝试不同版本组合

## 二、贪心

### 2.1 不是"感觉可以贪心"——要能证明

贪心跟 DP 的根本区别：DP 考虑所有子问题，选最优组合；贪心每步选当前看起来最好的，赌它会导致全局最优。

**贪心的核心不是选择策略，而是证明这个策略的正确性。**

两种经典证明方法：

**反证法**：假设贪心不是最优 → 用贪心解替换最优解的某个决策 → 得到不差于最优解的结果 → 矛盾 → 贪心就是最优。

**归纳法**：证明第一步贪心选择包含在某个最优解中 → 假设前 k 步正确 → 证第 k+1 步也正确。

### 2.2 经典贪心——无重叠区间

```java
// 最多能参加多少场不重叠的会议
// 贪心策略：按结束时间排序，每次选结束最早且不冲突的
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);  // 按结束时间升序
    
    int count = 0;
    int lastEnd = Integer.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] >= lastEnd) {
            count++;                    // 选中这场会议
            lastEnd = interval[1];
        }
    }
    return intervals.length - count;   // 需要移除的数量
}
```

**为什么按结束时间贪心是对的？** 反证法：假设最优解选了会议 A（结束较晚），那么把 A 替换为当前最早结束的会议 B（结束 ≤ A），B 不会比 A 阻碍更多后续会议（因为 B 更早结束）。替换后的解不差于最优解 → 贪心是最优解。

### 2.3 Python 实现

```python
def jump_game(nums):
    """跳跃游戏 II：最少跳跃次数到达终点
       贪心：在当前位置能跳到的范围内，选"能跳到最远"的位置作为下一跳
    """
    jumps = cur_end = cur_farthest = 0
    for i in range(len(nums) - 1):
        cur_farthest = max(cur_farthest, i + nums[i])
        if i == cur_end:               # 到达当前跳跃的边界
            jumps += 1
            cur_end = cur_farthest     # 必须跳了，跳到最远可达位置
    return jumps
```

### 2.4 实际场景

- **哈夫曼编码**：字符频率越高的编码越短 → 贪心建哈夫曼树（每次取两个最小的合并）
- **Dijkstra 最短路径**：每步选距离最小的未访问节点 → 贪心（可以用归纳法证明）
- **Prim/Kruskal 最小生成树**：Prim 每次选最短边连入，Kruskal 每次选最短边且不形成环
- **区间调度**：会议安排、CPU 任务调度——按结束时间贪心

## 三、BFS 与 DFS——图的两种遍历骨架

### 3.1 BFS——最短路径（无权图）

```java
// BFS 骨架——层序遍历
public int bfs(Node start, Node target) {
    Queue<Node> queue = new LinkedList<>();
    Set<Node> visited = new HashSet<>();
    
    queue.offer(start);
    visited.add(start);
    int steps = 0;
    
    while (!queue.isEmpty()) {
        int size = queue.size();          // 当前层的节点数
        for (int i = 0; i < size; i++) {
            Node cur = queue.poll();
            if (cur == target) return steps;
            
            for (Node next : cur.neighbors) {
                if (!visited.contains(next)) {
                    queue.offer(next);
                    visited.add(next);
                }
            }
        }
        steps++;                          // 层数递增
    }
    return -1;
}
```

**BFS 解决什么**：无权图的最短路径（BFS 第一次到达 target 时走过的层数就是最短距离）。BFS 也用队列实现树的层序遍历。

### 3.2 DFS——连通性、环检测、拓扑排序

```python
# DFS 骨架——递归 + visited
def dfs(graph, node, visited):
    visited.add(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

# 环检测（有向图）——三色标记法
def has_cycle(graph):
    WHITE, GRAY, BLACK = 0, 1, 2      # 未访问 / 访问中 / 已完成
    color = {node: WHITE for node in graph}
    
    def dfs(node):
        color[node] = GRAY
        for neighbor in graph[node]:
            if color[neighbor] == GRAY:
                return True            # 遇到"访问中"节点 → 有环！
            if color[neighbor] == WHITE and dfs(neighbor):
                return True
        color[node] = BLACK
        return False
    
    for node in graph:
        if color[node] == WHITE and dfs(node):
            return True
    return False
```

**GRAY 标记的必要性**：如果只用一个 visited（二值标记），分不清"正在访问的祖先节点"和"之前路径访问过的兄弟节点"。GRAY = 还在当前 DFS 路径上，遇到 GRAY 就是遇到祖先 = 环。

### 3.3 实际场景

- **BFS**：社交网络的"六度人脉"查询、地图导航（无权时）、网页爬虫的广度抓取
- **DFS**：编译器依赖图解析（循环依赖检测 = 环检测）、数据库死锁检测（wait-for graph 找环）

## 四、拓扑排序

### 4.1 Kahn 算法——BFS + 入度表

```java
public List<Integer> topologicalSort(int n, int[][] prerequisites) {
    // 1. 建图 + 入度表
    List<Integer>[] graph = new ArrayList[n];
    int[] indegree = new int[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int[] pre : prerequisites) {
        graph[pre[1]].add(pre[0]);  // pre[1] → pre[0]
        indegree[pre[0]]++;
    }
    
    // 2. 入度为 0 的节点入队
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) queue.offer(i);
    }
    
    // 3. BFS：每出队一个节点，它的邻居入度 -1
    List<Integer> order = new ArrayList<>();
    while (!queue.isEmpty()) {
        int node = queue.poll();
        order.add(node);
        for (int next : graph[node]) {
            if (--indegree[next] == 0) {
                queue.offer(next);
            }
        }
    }
    
    // 4. 结果长度 < n → 有环（无法完成拓扑排序）
    return order.size() == n ? order : new ArrayList<>();
}
```

### 4.2 实际场景

- **Maven/Gradle 依赖解析**：每个包是一个节点，依赖关系是有向边。拓扑排序确定构建顺序
- **任务调度**：Airflow DAG——每个 task 完成后触发下游 task（拓扑排序顺序）
- **课程表问题**（LeetCode 207/210）——拓扑排序的经典表述
- **Kafka Streams 拓扑**：processor 节点之间的数据流 = DAG 的拓扑序

## 五、Dijkstra 最短路径

### 5.1 BFS + 优先队列

```java
public int[] dijkstra(int n, List<int[]>[] graph, int start) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    // 优先队列：(距离, 节点)
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, start});
    
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        
        if (d > dist[u]) continue;   // 过时的距离信息，跳过
        
        for (int[] edge : graph[u]) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
}
```

**Dijkstra 不能处理负权边的原因**：算法假设一旦一个节点被从优先队列中弹出（即被"确定"），它的最短距离就不再变。但负权边可能让"已确定的节点"通过负权路径到达，打破"已确定=最短"的不变式。如果图中可能有负权边，用 Bellman-Ford 替代——O(VE)，但能处理负权且能检测负环。

### 5.2 Python 实现

```python
import heapq

def dijkstra(graph, start):
    """graph = {node: [(neighbor, weight), ...]}"""
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    pq = [(0, start)]
    
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    
    return dist
```

### 5.3 实际场景

- **地图导航**：道路有权重（距离/时间/拥堵度）→ Dijkstra 找最短路径
- **网络路由**：OSPF（链路状态路由协议）——每台路由用 Dijkstra 计算到达所有目标的最短路径
- **游戏 AI 寻路**：网格地图用 A*（Dijkstra + 启发式函数），无启发式时退化为 Dijkstra

## 六、并查集（Union-Find）

### 6.1 路径压缩 + 按秩合并

```java
class UnionFind {
    int[] parent;
    int[] rank;   // 树的高度（近似）
    
    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);   // 路径压缩
        }
        return parent[x];
    }
    
    public void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        // 矮树挂到高树上——按秩合并
        if (rank[px] < rank[py]) {
            parent[px] = py;
        } else if (rank[px] > rank[py]) {
            parent[py] = px;
        } else {
            parent[py] = px;
            rank[px]++;
        }
    }
}
```

**性能**：路径压缩 + 按秩合并后，`α(n)` 是阿克曼函数的反函数——对任何实际 n（甚至宇宙原子数），`α(n) ≤ 5`。所以 find/union 接近 O(1)。

### 6.2 Python 实现

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.rank[px] < self.rank[py]:
            self.parent[px] = py
        elif self.rank[px] > self.rank[py]:
            self.parent[py] = px
        else:
            self.parent[py] = px
            self.rank[px] += 1
        return True
```

### 6.3 实际场景

- **社交网络好友圈**：每个用户是一个节点，好友关系是边。连通分量个数 = 独立社交圈数
- **Kruskal 最小生成树**：每次选最短边，用并查集判断两端是否已连通（防止成环）
- **网络连通性**：数据中心交换机拓扑——哪些服务器在同一个 VLAN 可达
- **LeetCode 岛屿数量**：每个格子的四个方向做 union，最后数有多少个不同根节点
