# 双指针、滑动窗口、前缀和与单调栈——线性结构的四种优化范式

> 这四种技巧的共同点是：把 O(n²) 的暴力穷举优化到 O(n)。不需要复杂的数据结构，只需要巧妙地维护指针位置或前缀信息。面试中 80% 的线性结构题，都是这四种范式的变体。

---

## 一、双指针

### 1.1 快慢指针

两个指针以不同速度向前移动。核心价值：**不用额外空间，在 O(n) 时间内检测链表结构**。

**模板骨架**：

```java
// 快慢指针标准模板
ListNode fast = head, slow = head;
while (fast != null && fast.next != null) {
    slow = slow.next;          // 慢指针走一步
    fast = fast.next.next;     // 快指针走两步
}
// slow 停在中间（奇数个节点在正中，偶数个在右中）
```

**Floyd 判圈算法——为什么相遇后慢指针回到起点，两人同速走会在环入口相遇？**

```
设: 链表头到环入口距离 = a, 环长 = L
   相遇时慢指针在环内走了 x, 快指针走了 a + x + kL

由于快指针速度是慢指针的 2 倍:
  2(a + x) = a + x + kL
  a = kL - x = (k-1)L + (L - x)

这意味着：从链表头到环入口的距离 a，等于"从相遇点走 (k-1)L + (L-x)"的距离。
而 L-x 刚好是相遇点到环入口的距离（在环内继续走）。
所以慢指针回到 head，两人同速走: 慢从 head 走 a 步到环入口，快从相遇点走 (k-1)L + a 步也到环入口。相遇。
```

**Java 实现**：

```java
// 链表判环 + 找入口
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {       // 相遇 → 有环
            slow = head;           // 慢指针回起点
            while (slow != fast) { // 两人同速走
                slow = slow.next;
                fast = fast.next;
            }
            return slow;           // 再次相遇 = 环入口
        }
    }
    return null;
}

// 找中点（归并排序的分治依赖）
public ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;  // 前半段的最后一个节点（方便断开链表）
}
```

### 1.2 左右指针（对撞指针）

两个指针从数组两端向中间移动。核心价值：**利用有序性，将两层遍历压缩为一层**。

**模板**：

```python
def two_sum_sorted(nums, target):
    """有序数组的两数之和——O(n)"""
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return [l, r]
        elif s < target:
            l += 1       # 和太小 → 左指针右移（增大和）
        else:
            r -= 1       # 和太大 → 右指针左移（减小和）
    return []
```

**三数之和的去重技巧**：

```python
def three_sum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if nums[i] > 0: break                     # 剪枝：最小数 > 0 → 无解
        if i > 0 and nums[i] == nums[i - 1]:
            continue                               # 去重：跳过重复的 i
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]: l += 1  # 去重 l
                while l < r and nums[r] == nums[r - 1]: r -= 1  # 去重 r
                l += 1; r -= 1
            elif s < 0:
                l += 1
            else:
                r -= 1
    return res
```

**有序数组的两数之和、三数之和为什么要排序？** 排序后，右指针左移一定让和变小，左指针右移一定让和变大——这种单调性是对撞指针有效的前提。

### 1.3 实际场景

- **RingBuffer 读写指针**：两个指针在循环缓冲区中跑，生产者移动写指针，消费者移动读指针
- **GC 标记阶段**：从 GC Roots 出发，快慢指针遍历对象引用图，标记可达对象
- **有序数据的合并**：两个有序数组/文件的 merge 操作 = 双指针并行前进
- **回文检测**：左右指针从两端向中间比较字符

## 二、滑动窗口

### 2.1 核心原理

滑动窗口解决的是**连续子数组/子串的最优条件**问题。暴力解法 O(n²)，滑动窗口 O(n)。

**为什么是 O(n)？** 因为 left 和 right 两个指针各自只遍历一次——right 只增不减（扩张），left 只增不减（收缩）。总移动次数 2n = O(n)。

**模板骨架**：

```python
def sliding_window(s):
    left = 0
    window = {}    # 窗口内元素统计
    
    for right in range(len(s)):
        # 1. right 扩张：加入新元素
        window[s[right]] = window.get(s[right], 0) + 1
        
        # 2. 窗口条件不满足 → left 收缩
        while 窗口不满足条件:
            window[s[left]] -= 1
            if window[s[left]] == 0:
                del window[s[left]]
            left += 1
        
        # 3. 更新最优解（此时窗口满足条件）
        update_result(right - left + 1)
```

### 2.2 Java 实现——无重复字符最长子串

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> window = new HashMap<>();
    int left = 0, maxLen = 0;
    
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window.put(c, window.getOrDefault(c, 0) + 1);
        
        // 窗口内有重复 → 收缩 left
        while (window.get(c) > 1) {
            char d = s.charAt(left);
            window.put(d, window.get(d) - 1);
            left++;
        }
        
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

### 2.3 Python 实现——最小覆盖子串

```python
from collections import Counter

def min_window(s, t):
    """s 中涵盖 t 所有字符的最小子串"""
    need = Counter(t)               # 需要的字符及其个数
    window = {}
    left = 0
    formed = 0                      # 已满足的字符种类数
    min_len, start = float('inf'), 0
    
    for right, ch in enumerate(s):
        window[ch] = window.get(ch, 0) + 1
        if window[ch] == need.get(ch, 0):
            formed += 1             # 这个字符的数量刚达标
        
        # 所有字符都达标 → 尝试收缩 left
        while formed == len(need):
            if right - left + 1 < min_len:
                min_len = right - left + 1
                start = left
            
            d = s[left]
            window[d] -= 1
            if window[d] < need.get(d, 0):
                formed -= 1         # 失去这个字符的达标状态
            left += 1
    
    return s[start:start + min_len] if min_len != float('inf') else ""
```

### 2.4 实际场景

- **流量限流**：过去 1 秒的请求数 → 滑动窗口计数器。比固定窗口精确（固定窗口在边界处存在突刺问题）
- **TCP 拥塞控制**：拥塞窗口（cwnd）动态调整——ACK 到达时 cwnd 变大（扩张），丢包时 cwnd 缩小（收缩）
- **Kafka Consumer 拉取**：每次 poll 拉取 N 条消息 → 处理完的提交 offset → offset 就是窗口左边界，拉取位置是右边界
- **日志序列中的异常模式匹配**：在日志流中滑动窗口检测连续异常序列

## 三、前缀和

### 3.1 核心原理

`prefix[i] = sum(arr[0..i])`。子数组和 `sum(arr[i..j]) = prefix[j] - prefix[i-1]`。

单用前缀和是 O(n²)（枚举所有 i,j 组合）。配上 HashMap 能做到 O(n)：当我们走到位置 j 时，想知道"有没有某个 i 满足 prefix[j] - prefix[i] = target"→ 等价于"prefix[i] = prefix[j] - target 是否在之前的遍历中出现过"。

### 3.2 Java 实现——和为 K 的子数组

```java
public int subarraySum(int[] nums, int k) {
    // prefix -> 出现次数
    Map<Integer, Integer> preSumCount = new HashMap<>();
    preSumCount.put(0, 1);  // 前缀和为 0 出现过一次（空数组）
    
    int preSum = 0, count = 0;
    for (int num : nums) {
        preSum += num;
        // 找之前有多少个 prefix[i] == preSum - k
        count += preSumCount.getOrDefault(preSum - k, 0);
        preSumCount.put(preSum, preSumCount.getOrDefault(preSum, 0) + 1);
    }
    return count;
}
```

### 3.3 Python 实现——二维前缀和

```python
# 二维前缀和：pre[i][j] = 以 (i,j) 为右下角的矩形和
# 子矩阵和 = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]

class NumMatrix:
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        self.pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                self.pre[i+1][j+1] = (self.pre[i][j+1] + self.pre[i+1][j]
                                       - self.pre[i][j] + matrix[i][j])
    
    def sum_region(self, x1, y1, x2, y2):
        return (self.pre[x2+1][y2+1] - self.pre[x1][y2+1]
                - self.pre[x2+1][y1] + self.pre[x1][y1])
```

### 3.4 实际场景

- **数据库脏页统计**：InnoDB 统计 buffer pool 中每个分区的脏页比例——用前缀和维护分区累积值，快速查询任意区间的脏页数
- **Kafka 消息累积量**：每个分区的 `endOffset - committedOffset` 就是消费 lag。sum 所有分区 lag = 消费者组总 lag
- **监控系统的区间聚合**：Prometheus 的 `rate()` 函数计算时间窗口内的平均速率，相当于前缀和的区间差值
- **日活/UV 的区间查询**："过去 7 天的新增用户数" = 今天的前缀 - 7 天前的前缀

## 四、单调栈与单调队列

### 4.1 单调栈——找到每个元素的下一个更大/更小值

**核心思想**：维护一个栈内元素单调递增或递减的栈。遍历数组时，每个元素入栈前，弹出所有破坏单调性的元素——这些被弹出的元素，"下一个更大值"就是当前元素。

```python
# 下一个更大元素（Next Greater Element）——单调递减栈
def next_greater_element(nums):
    n = len(nums)
    ans = [-1] * n
    stack = []                      # 存下标，栈内 nums 值单调递减
    
    for i in range(n):
        # 当前元素比栈顶大 → 栈顶元素的"下一个更大"就是当前元素
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            ans[idx] = nums[i]
        stack.append(i)
    
    return ans

# nums = [2, 1, 2, 4, 3] → ans = [4, 2, 4, -1, -1]
```

**为什么存下标而不存值？** 因为答案数组需要知道"第几个元素"的下一个更大值是什么。存下标能同时拿到值和位置。

### 4.2 单调队列——滑动窗口最大值

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> deque = new ArrayDeque<>();  // 存下标，对应的 nums 值递减
    int[] ans = new int[nums.length - k + 1];
    
    for (int i = 0; i < nums.length; i++) {
        // 1. 移除队尾所有比当前元素小的（它们永远不可能成为窗口最大值）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
        
        // 2. 移除队首超出窗口范围的元素
        if (deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }
        
        // 3. 窗口形成后，队首就是当前窗口最大值
        if (i >= k - 1) {
            ans[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return ans;
}
```

单调队列与单调栈的区别：栈只操作一端（栈顶），队列可以操作两端（队头移除过期、队尾维护单调性）。

### 4.3 实际场景

- **股票价格跨度**（LeetCode 901）："今天之前连续多少天价格不高于今天" → 单调递减栈。Google/Apple 等公司的面试高频题
- **柱状图中最大矩形**：找每个柱子左右两边第一个比它矮的柱子 → 单调递增栈
- **浏览器前进/后退**：两个栈——后退栈 + 前进栈
- **编辑器撤销/重做**：操作历史栈 + 撤销后的操作栈

---

四种范式比较：

| 范式 | 核心思想 | 时间复杂度 | 典型问题 |
|------|---------|-----------|---------|
| 双指针 | 两个指针交替/同步移动 | O(n) | 链表判环、有序两数之和 |
| 滑动窗口 | right 扩张 + left 收缩 | O(n) | 无重复字符子串、最小覆盖子串 |
| 前缀和+HashMap | `prefix[j]-prefix[i-1]=k` | O(n) | 和为 K 的子数组 |
| 单调栈 | 维护单调性，找到"下一个更大/更小" | O(n) | 每日温度、柱状图最大矩形 |

它们的共同本质：利用数据中的**单调性或前缀关系**，在一次遍历中通过维护辅助结构（窗口/前缀和/栈），避免重复计算。面试时拿到一道线性结构的题，先问自己"这四个范式哪个适用"，可以迅速收窄思路。
