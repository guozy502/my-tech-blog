一、整型——每个数字都要想清楚"最大是多少"

1.1 四种整型的真相

类型 字节数 有符号范围 无符号范围 “够用"的场景
TINYINT 1 -128 ~ 127 0 ~ 255 状态码、布尔值、年龄
SMALLINT 2 -32768 ~ 32767 0 ~ 65535 年份、端口号、小型计数器
MEDIUMINT 3 -838 万 ~ 838 万 0 ~ 1677 万 中型计数器（很少用）
INT 4 -21 亿 ~ 21 亿 0 ~ 42 亿 主键、用户 ID、大部分计数器
BIGINT 8 -9 京 ~ 9 京 0 ~ 1844 京 自增主键（防止溢出）、金额（存分）、时间戳（毫秒）

选择原则只有一条：预估字段的最大可能值，选择刚好能兜底的最小类型。
